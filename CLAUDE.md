# SJ Consultancy - Agent Guidelines

## Commands
- Run dev: `npm run dev`
- Build: `npm run build`
- Lint: `npm run lint`

## Architecture
- Next.js 16 App Router with Turbopack & React 19
- Tailwind CSS v4 via `@tailwindcss/postcss`
- Components in `src/components/{layout,sections,ui}`
- Pages in `src/app/{about,contact,process,services}`
